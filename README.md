# AI VOICE Visualizer

音に反応して動く、青く光る球体のビジュアライザーです。

**公開ページ：https://tsubasa0518.github.io/visualizer/**

- ドラマや作品の公式のものではありません。個人が作った試作品です。
- Claude や、ほかのサービスの公式アプリではありません。
- 音声については、API もキーも使いません。音声はブラウザーの中で調べるだけです。録音・保存・送信はしません。
- 天気の表示のためだけに、天気サービス（Open-Meteo）に通信します。音声は送りません。くわしくは、「録音や送信について」と「日付と天気の枠」を見てください。

## 声に反応する仕組み

### 何が起きるか

声や音がマイクに入ると、次のことが起きます。

- 球体が少しふくらみます。いちばん大きいときで、元の約 1.08 倍です。
- 球体の粒が明るくなり、少し大きくなります。中心の光も強くなります。
- 画面の数値が変わります。公開ページでは、`SIGNAL MONITOR` と `SYNCHRONIZATION` の 2 か所が、同じ値（0〜100%）で動きます。

### 仕組み（公開ページ `index.html`）

1. **マイクの音を受け取る。**
   ブラウザーの機能 `getUserMedia`（マイクを使わせてもらう命令）で、マイクの音を受け取ります。そのとき、ブラウザーの自動補正（エコー消し、雑音抑え、自動の音量調整）は切っています。
2. **音の大きさを、0〜100%の数値にする。**
   Web Audio API（ブラウザーにある、音を調べる機能）で、音の波の形を毎回読み取ります。
   そこから「音の強さ」を計算します。波の大きさを 2 乗して平均し、ルートをとる方法です（RMS といいます）。
   小さな雑音の分を引き、31 倍して、0〜1 の範囲に収めます。最後に 0.7 乗して、小さな声にも反応しやすくしています。この値が 0〜100% の数字です。
3. **その数値で、見た目を変える。**
   数値に合わせて、球体の大きさ、粒の明るさと大きさ、中心の光、まわりの輪とぼんやりした光、画面の数値を変えます。

**速く反応して、ゆっくり戻る。**
音が大きくなるとき（上がるとき）は、1 回の描き直しごとに、目標との差の 20% ずつ追いかけます。
音が小さくなるとき（下がるとき）は、7% ずつです。だから、反応は速く、戻りはゆっくりです。
球体の見た目には、さらに 14% ずつ追いかける、もう 1 段なめらかな値を使います。画面の数字は、この 1 段前の値です。

### 録音や送信について

**音声（マイクの音）**について、コードを検索して確認した範囲では、次のとおりです。

- **録音していません。** 録音の機能（`MediaRecorder`）は、公開ページにはありません。
- **音声を送っていません。** マイクの音を、どこかへ送る命令はありません。音声は、ブラウザーの中で大きさを調べるだけです。
- **保存していません。** 端末に保存する命令（`localStorage`、`sessionStorage`、`indexedDB`、`cookie`）は、公開ページにはありません。
- **公開ページは、マイクの音をスピーカーから出しません。** 音を調べる部品に、スピーカーへの出口がつながっていないためです。
- **マイクは止められます。** 「マイクを停止」を押したとき、またはページを閉じるときに、マイクの使用をやめます。

**天気の取得**について、確認した範囲では、次のとおりです。

- 天気を出すために、公開ページは `api.open-meteo.com`（Open-Meteo という外部サービス）に通信します。通信の命令（`fetch`）は、天気のための 1 か所だけです。
- 送る内容は、**場所の座標**（緯度 35.4、経度 139.6）です。市区町村より細かくしないで、小数第 1 位までにしています。音声は送りません。ブラウザーの位置情報の機能も使っていません。
- 相手のサーバーには、見ている人の **IP アドレスなど**が、ふつうのインターネット通信として届きます。これは、外部のサービスを使うサイトでは同じです。Open-Meteo の利用条件には、無料の API では、IP アドレスを不正利用の防止などのために集めることがあり、座標をふくむ記録は 90 日で消す、と書かれています（2026-10-31 に確認）。
- 通信には、このページのアドレス（参照元）を付けない設定（`referrerPolicy: 'no-referrer'`）にしています。
- 外部のスクリプト、スタイルシート、フォントは、増やしていません。**通信先は `api.open-meteo.com` だけ**です。画面の下の出典リンクは、押したときだけ移動します。

確認できていない範囲もあります。ブラウザーそのものの動きや、GitHub 側のサーバーの動きは、このコードからはわかりません。

### うまく動かないとき

**公開ページで、画面の下に出る文**

| 文 | いつ出るか |
| --- | --- |
| 「マイクへのアクセスを許可してください。」 | マイクの許可をしなかった、またはブロックされているとき |
| 「マイクは localhost または HTTPS 環境で利用してください。」 | ブラウザーに、マイクを使う機能がないとき |
| ブラウザーが返す文がそのまま出る | 上の 2 つ以外のエラー。文の内容は**未確認** |

**天気の枠が `OFFLINE` になっているとき**

- 天気を取れていません。ネットワークにつながっているか、確認してください。5 分ごとに、自動でやり直します。
- 球体とマイクの動きには、影響しません。

**確認すること**

- マイクの許可：「マイクを接続」を押すと、ブラウザーが確認を出します。「許可」を選びます。
- 一度ブロックしたとき：Chrome では、アドレスバーの左のアイコンから「サイトの設定」を開き、マイクを「許可」にして、再読み込みします。（ブラウザーの画面での確認は、**未確認**です。）
- HTTPS または localhost：マイクは、`https://` で始まるページか、自分のパソコンの中だけで動かす `localhost` のページでしか使えません。公開ページは HTTPS です。
- ブラウザー：公開ページを Chrome で開いて、表示されることは確認しました。マイクが実際に動くかは、**未確認**です。ほかのブラウザーも**未確認**です。
- 公開ページには、「音が届いていない」という案内はありません。球体が動かないときは、マイクの音量や、ほかのアプリがマイクを使っていないかを見てください。

## 日付と天気の枠

公開ページの右側にある、四角い枠です。

| 表示 | 内容 |
| --- | --- |
| 日付と曜日 | 例：`2026年10月31日（土）`。英語の曜日（`SAT`）も小さく出ます |
| 天気 | 日本語の文字（例：晴れ、くもり、雨） |
| 気温 | 小数第 1 位まで（例：`18.4°C`） |
| 湿度 | 整数（例：`62%`） |
| 最終更新 | 日本時間の `HH:MM`（天気を最後に取れた時刻） |
| 場所 | 初期値は `KANAGAWA` |

- **日付と曜日**は、見ている人の端末の時間ではなく、**日本時間（Asia/Tokyo）**で出します。ページを開いたままでも、1 分ごとに確認して、日付が変わると直ります。
- **天気・気温・湿度**は、Open-Meteo（無料の天気データのサービス）の「現在の値」です。ページを開いたときに取り、そのあとは 30 分ごとに更新します。取れなかったときは、5 分後にもう一度やります。1 回の待ち時間は、最長 8 秒です。
- **取れなかったとき**は、天気・気温・湿度が `--` になり、小さく `OFFLINE` と出ます。日付と曜日は、そのまま表示されます。球体とマイクの動きには、影響しません。
- **場所を変えたいとき**は、`index.html` の後ろの方にある 2 つ目の `<script>` の先頭の、3 つの値（場所の名前、緯度、経度）を書き換えます。座標は、市区町村より細かくしないで、小数第 1 位までにしてください。
- 画面の幅が 880px 以下、または高さが 739px 以下のときは、枠を隠します。ほかの文字や球体と重ならないようにするためです。
- 画面の下の説明文にも、出典のリンクがあります。

**出典：** Weather data by [Open-Meteo.com](https://open-meteo.com/)（ライセンス：[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)）

Open-Meteo の公式の利用条件には、無料の API は**非営利の利用だけ**が対象と書かれています（2026-10-31 に確認）。

## 公開ページ（index.html）でできること

- 青い光の粒の球体が、ゆっくり回ります。
- 声や音が大きいと、球体がふくらみ、光が強くなります。
- 「マイクを接続」ボタンで、パソコンのマイクの音に反応します。（スマホでの動きは**未確認**です。）
- 画面の数字（SIGNAL MONITOR と SYNCHRONIZATION）が、音の大きさに合わせて変わります。
- 画面の右側に、日付・曜日・天気・気温・湿度の枠を表示します（日本時間）。

### できないこと（公開ページ）

- タブの音声を取り込むこと
- 全画面ボタン、キー操作、文字を隠すモード
- 音の大きさ（感度）の調整
- マイクを選ぶこと（ブラウザーの標準のマイクを使います）
- 3D 版の表示

## 使い方（公開ページ）

1. 公開ページを開きます。
2. 「マイクを接続」を押します。
3. ブラウザーが聞いてきたら、マイクを「許可」します。
4. 話しかけるか、スピーカーから音を流します。球体が動きます。
5. 止めるときは「マイクを停止」を押します。

### ブラウザーの条件

- 公開ページは HTTPS なので、マイクが使えます。
- マイクを許可していないと、動きません。ブロックした場合は、アドレスバー左のアイコンから「サイトの設定」を開き、マイクを「許可」にして、再読み込みします。
- パソコン版の Chrome または Edge での動作を想定しています。（Safari など、ほかのブラウザーは未確認です。）
